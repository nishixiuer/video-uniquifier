# 从视频素材到主页自动发布

主流程：**素材库 → 批量制作 → 内容库 → 主页规则 → 发布任务**。
独立视频处理、调参、指纹索引和手动文案工具仍可从侧栏其他分组进入。

## 1. 保存素材与资料

在“素材库”导入 MP4、MOV、MKV 或 WebM 视频。应用保存本机副本，并通过原核心
`probe` 读取真实时长和画面尺寸。填写名称、剧情介绍/推广资料、分类及标签。
资料完整且已启用的视频才能制作；分类和标签会自动继承到生成内容。

一条素材记录对应一个源视频。多选素材可使用同一批制作参数，每个视频仍按自己的
资料生成文案。无须迁移原项目的企业、价格、云存储或数据库。

## 2. 创建批量制作任务

在素材行点击“制作帖子”，或多选后点击“批量制作”。填写：

- 每段时长、每个视频的条数、起点，以及连续分段或均匀选段。
- 720p/1080p 竖屏输出、画质和镜头分析。
- 文案语种、提示词、AI/离线模板、追加标签，以及入库审核状态。

先预览剪片计划再创建任务。区间不会重叠；时长不足会阻止创建。
只制作一条且源视频较短时，使用起点之后的剩余时长。同一素材、相同起止区间
已有未取消制作项时，不会重复创建；失败项应在原批次中重试。

批次按创建顺序逐项执行：**视频制作 → 推广文案 → 内容入库**。
视频处理调用既有 `jobs.submit(kind=reels)`，复用原项目的 `ReelsRules`、
`process_video`、质量检查和报告。规则先经真实 YAML/Pydantic Schema 校验；
未另造一套与原核心脱节的编码逻辑。

AI 接口和提示词在“服务配置”统一管理。创建批次时会保存来源资料、规则、提示词、
接口/模型及加密密钥快照；后续编辑配置不会改变已排队的批次。
AI 只收到本条视频的名称、文字资料、分类/标签、片段区间和视频元数据，不上传视频。
程序按明确的时间规则剪片，不会自动识别剧情高潮或理解未提供的画面内容。

## 3. 查看进度与恢复

“批量制作”的制作记录和详情显示每项阶段、进度、错误与关联成片。

| 操作 | 行为 |
| --- | --- |
| 暂停批次 | 停止启动/检查下一制作项；已经提交的视频编码及正在请求的文案可能继续 |
| 继续 | 继续处理该批次的待完成项 |
| 重试失败项 | 已成功成片会复用，只重试失败阶段；成功项不会重复入库 |
| 取消待完成项 | 保存取消状态，取消已知视频任务并中断当前 AI 请求；成功内容保留 |
| 退出/重开 | 恢复持久化批次；已完成成片复用，AI 阶段恢复；被退出中断的编码项显示失败并可重试 |

视频提交使用持久化请求编号，提交响应中断后重试不会创建重复编码任务。
每个制作项只创建一条内容。所有状态独立于当前页面，切换页面不会取消任务。

## 4. 内容库审核与追溯

内容库统一保存成片、推广文案、语种、标签、审核状态及来源关联。
可按来源、标签、审核状态和发布状态筛选，查看制作记录、发布状态。

生成内容保留：素材 ID、素材名称、批次 ID、制作项 ID、处理任务 ID 和起止区间。
“预览”使用内置播放器；“视频对比”和“质量报告”沿用已有双视频同步、参数对比和
可读报告窗口。不会启动系统默认播放器。

默认待审核；也可在创建批次时明确选择直接审核。只有已审核内容才能被发布规则选中。
素材已有制作记录时不能删除来源记录，可停用。停用后会阻止新制作、自动选稿及
关联的待发布任务，已发送的请求不会被撤回；历史内容、报告及发布记录保留。

## 5. 授权主页并按规则发布

在“服务配置”保存自己的 Meta 应用，然后到“主页授权”连接账号拥有的 Facebook 主页。
发布目标是官方 Page，每个主页独立设置启用状态、匹配标签、每日额度、间隔、时间窗和发布类型。

调度器选取命中任一标签、已审核、来源启用、未分配过任务的最早内容。
一条内容全局只分配一次，多个主页不会抢到同一条内容。新主页默认每天 5 条、
间隔 1 小时、全天窗口；已有主页保存的规则不覆盖。额度按滚动 24 小时计算。
选择 Reels 类型时仅匹配单视频内容。

“发布任务”显示远端处理、结果链接、失败与需核实状态。定时执行要求应用保持运行。
授权、状态及重试规则详见 [PUBLISHING.md](PUBLISHING.md)。

## 数据与验证

`userData/publishing/production.json` 保存素材与制作批次，`publishing.json` 保存内容、
主页及发布任务，`media/` 保存素材与成片副本。凭据只写入加密存储。
视频任务、原始报告仍保存在 `userData/engine/`，制作关联任务不会因普通历史条数上限被淘汰。
旧版手动创建的内容和已有发布任务保持可用。

单元测试覆盖规划、配置校验、快照、失败/取消/重启、提交幂等、标签继承和跨主页占用。
Electron 测试实际导入视频、调用 FFmpeg 制作两段，连接本机模拟 AI 服务生成文案，
检查成片时长、预览、对比、报告、模板管理及重启恢复。Graph API 使用模拟接口，
不会真实发帖。

当前实现视频生产主链路及来源/标签筛选、提示词管理。多 AI 配置并存选择、
图片合成视频等扩展仍在后续范围；原有手动图片帖子及文案工具可继续使用。
